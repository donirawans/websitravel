# Travel & Tour Booking Website

*Antarmuka website agen perjalanan wisata dan pemesanan tiket berbasis web statis yang responsif.*

</div>

---

## Ringkasan Proyek

Repositori ini memuat kode sumber website travel dan eksplorasi destinasi wisata berbasis web front-end statis. Proyek ini dirancang untuk menyajikan informasi paket perjalanan, rekomendasi destinasi wisata populer, serta antarmuka alur pemesanan tiket (*ticketing*) yang mudah digunakan oleh calon wisatawan.

---

## Fitur Halaman

- Landing Page Destinasi: Halaman utama yang memuat promosi paket wisata, kurasi tempat liburan terpopuler, dan fasilitas tur.
- Modul Pemesanan Tiket: Halaman antarmuka khusus untuk memilih jadwal keberangkatan, rute tur, dan pemesanan tiket perjalanan.
- Desain Responsif: Tata letak antarmuka yang fleksibel dan tetap proporsional saat diakses melalui perangkat desktop maupun layar ponsel.
- Navigasi Interaktif: Akses cepat antar-menu informasi tur, galeri destinasi, dan form reservasi tiket.

---

## Teknologi yang Digunakan

- HTML5: Penyusunan kerangka semantik halaman web dan struktur form input tiket.
- CSS3: Penataan tampilan, tipografi, warna tema perjalanan, kartu destinasi, dan tata letak responsif (Flexbox/Grid).
